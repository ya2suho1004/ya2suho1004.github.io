개인정보처리방침

cadassist의 Google Workspace와 YouTube 연동에서 데이터를 처리하는 방식입니다.

접근하는 데이터와 이용 목적

Google 계정 소유자가 승인한 권한에 따라 Gmail 메시지와 라벨, 캘린더 일정, Drive 파일, Google 문서와 스프레드시트, 연락처에 접근합니다. Hermes는 계정 소유자의 요청이나 계정 소유자가 설정한 자동화에 필요한 데이터를 읽고, 승인된 범위에서 메시지 발송, 일정 및 파일·문서 변경을 처리합니다.

저장 및 공유

Google OAuth 자격 증명은 계정 소유자가 관리하는 Hermes 환경에 저장합니다. Google API에서 읽은 정보는 실행 중에 처리되며, 계정 소유자가 저장을 요청하거나 작업 기록에 저장되는 경우 해당 환경에 남을 수 있습니다. 계정 소유자가 동의하여 AI 처리 또는 메시지 전달을 설정한 경우, 해당 작업에 필요한 정보가 선택한 모델 제공자나 메시징 서비스로 전송될 수 있습니다.

Google API에서 받은 정보의 이용과 전송에는 Google Workspace API 사용자 데이터 및 개발자 정책의 제한적 사용 요건을 적용합니다.

Google Workspace API의 제한적 사용 요건

YouTube 연동

채널 소유자가 승인하면 YouTube API Services를 통해 채널과 동영상 정보, 조회수·시청 시간 등 성과 지표, 댓글과 작성자 표시 이름을 읽습니다. Hermes는 이 정보를 성과 보고서와 댓글 검토 자료를 만드는 데 사용합니다.

YouTube 연동의 데이터 저장·공유·삭제 안내

연결 해제와 데이터 관리

계정 소유자는 Google 계정의 서드 파티 연결에서 cadassist 접근 권한을 철회하고, Hermes 환경에 저장된 자격 증명과 작업 기록을 관리할 수 있습니다. 문의는 Google OAuth 동의 화면의 사용자 지원 이메일을 이용할 수 있습니다.
